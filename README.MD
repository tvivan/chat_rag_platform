# RAG-платформа для PDF Документов

Это продвинутая RAG (Retrieval-Augmented Generation) платформа, спроектированная для эффективной работы с PDF-документами на русском языке. Система способна анализировать пакет документов, включая сложные структуры, такие как таблицы, и отвечать на вопросы, основываясь исключительно на их содержании.

## Ключевые особенности

-   **Продвинутая стратегия индексации текста:** Используется `ParentDocumentRetriever`, который решает проблему потери контекста. Поиск ведется по маленьким, точным фрагментам, а для генерации ответа модели передается большой, осмысленный родительский блок.
-   **Интеллектуальная обработка таблиц:** Применяется `MultiVectorRetriever` для семантического поиска по таблицам. Для каждой таблицы с помощью LLM генерируются гипотетические вопросы, которые векторизуются. Это позволяет находить таблицы по смыслу запроса, а не по точному совпадению.
-   **Надежная генерация данных (Structured Output):** Для создания гипотетических вопросов используется Pydantic-модель, что заставляет LLM возвращать строго структурированный JSON. Это делает процесс на 100% надежным и исключает ошибки парсинга.
-   **Высококачественные русскоязычные эмбеддинги:** Платформа использует `ai-sage/Giga-Embeddings-instruct` — мощную модель эмбеддингов, специально обученную для русского языка и задач поиска.
-   **Локальная и персистентная векторная база:** Qdrant настроен для хранения всех векторов локально на диске. Это означает, что данные индексируются один раз и сохраняются между запусками, делая последующие старты практически мгновенными.
-   **Модульная архитектура:** Код разбит на логические модули (`main.py` — оркестратор, `functions/` — ядро логики), что упрощает его понимание, поддержку и дальнейшее расширение.

## Архитектура проекта

```
project/
├── main.py                 # Главный файл: запускает приложение, собирает пайплайн
├── dataset/                # Папка для ваших PDF-документов
├── Qdrant_local_db/        # Папка, где Qdrant хранит локальную базу данных (создается автоматически)
├── endpoints/
│   └── endpoints.py        # Pydantic-модели для структурированных данных
└── functions/
    ├── document_reader.py  # Логика чтения, парсинга PDF и обработки таблиц
    ├── llm_setup.py        # Настройка и подключение к LLM (OpenRouter)
    └── qdrant_setup.py     # Настройка векторной базы Qdrant и модели эмбеддингов
```

## 🛠️ Технологический стек

-   **Язык:** Python 3.10+
-   **Основной фреймворк:** [LangChain](https://www.langchain.com/)
-   **Векторная база данных:** [Qdrant](https://qdrant.tech/) (локальный режим)
-   **Модель эмбеддингов:** [Hugging Face `ai-sage/Giga-Embeddings-instruct`](https://huggingface.co/ai-sage/Giga-Embeddings-instruct)
-   **LLM (для генерации):** Любая модель, доступная через [OpenRouter](https://openrouter.ai/) (например, Qwen, Claude)
-   **Парсинг документов:** [Unstructured.io](https://unstructured.io/)

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone
cd project
```

### 2. Создание виртуального окружения

Рекомендуется использовать виртуальное окружение для изоляции зависимостей.

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# macOS / Linux
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

Установите все зависимости одной командой:

```bash
pip install -r requirements.txt
```

*Примечание: для работы `torch` с GPU (настоятельно рекомендуется для эмбеддингов) может потребоваться установка специальной версии. См. официальный сайт [PyTorch](https://pytorch.org/).*

### 4. Настройка окружения

Создайте файл `.env` в корневой директории проекта и добавьте в него ваш API-ключ от OpenRouter:

```
OPENROUTER_API_KEY="sk-or-v1-..."
```

### 5. Добавление документов

Создайте папку `dataset` в корне проекта и поместите в нее ваши PDF-файлы, которые вы хотите проиндексировать.

### 6. Запуск приложения

```bash
python main.py
```

-   **При первом запуске:** Скрипт проиндексирует все документы из папки `dataset` и создаст локальную базу данных в папке `Qdrant_local_db`. Этот процесс может занять некоторое время.
-   **При последующих запусках:** Скрипт обнаружит существующую базу и запустится мгновенно, сразу перейдя в режим чата.

После запуска вы увидите приглашение для ввода вопроса. Введите вопрос и нажмите Enter. Для выхода введите `exit`.
